# OpenCart — Shipping & Tax Calculation Testing

## Project Overview

This project focuses on manual testing of the OpenCart e-commerce application, specifically the Shopping Cart, Shipping Estimation, Tax Calculation, and Cart Totals functionalities.

The objective is to evaluate the correctness and consistency of cart calculations across different user actions and session states.

## Project Objectives

- Validate shipping estimation and application workflows.
- Verify cart subtotal, shipping charges, and tax calculations.
- Identify calculation inconsistencies and data integrity issues.
- Validate cart behavior across page refreshes and user sessions.
- Perform regression testing on related cart functionalities.

## Scope of Testing

| Module | Testing Coverage |
|---|---|
| Shopping Cart | Product quantities and subtotal |
| Shipping Estimation | Destination selection and shipping quotes |
| Shipping Methods | Applying and changing shipping methods |
| Tax Calculation | Tax preservation and recalculation |
| Cart Totals | Total calculation and consistency |
| Session Management | Cart state persistence |
